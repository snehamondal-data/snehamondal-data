Detecting coded racism in football commentary

M.S. Data Science capstone, Rochester Institute of Technology, 2025. Advisor: Dr. Ashique Khudabukhsh

A hybrid NLP system, and an honest account of where it fails.

General toxicity classifiers catch slurs. They miss remarks like "tactical IQ" or "naturally athletic but lacking technical skill", which can be ordinary analysis or a stereotype depending on context. So the design treats those phrases as candidate cues resolved by context, not as a blocklist.

The system combines a fine-tuned BERT classifier (benchmarked against RoBERTa, which it beat at 0.72 vs 0.61 F1), a linear SVM over pooled [CLS] embeddings, and a rule layer of 60+ coded-language phrases with exemptions for football-analysis vocabulary, joined by a rule override and a majority vote. The data is 1,031 examples: 950 hand-labelled comments from YouTube, Reddit, Twitter and news, plus synthetic templates, including control examples that teach the model what not to flag.

Accuracy, held-out
75.2%
F1, racist class
0.68
Precision / recall, racist class
62.3% / 76.0%
Mean confidence when wrong / when right
0.82 / 0.69

The last line is the finding I would lead with. The model was most confident when it was wrong, so its confidence could not be used to route uncertain cases to a human as-is. That is a calibration failure, and the write-up reports it rather than burying it. One stage table in the poster lists 0.76 F1 for the final hybrid; I report the lower held-out figure.

Marketing data reliability pipeline, with an analytics agent on top

Personal project, 2026. Synthetic data for two brands

A pipeline where a rerun inserts zero rows, and an LLM agent tested like any other transformation.

Python ingestion from a paginated, rate-limited API (Retry-After backoff, watermark checkpoints, append-only loads) into DuckDB, then dbt staging and marts for two tenants. It reconciles ad spend against revenue net of refunds, reports MER, ROAS, AOV and CAC, and flags ad spend on products about to stock out. On the test data the alert fired 18 days before the stockout.

The agent takes a plain-English question and answers from the marts through three tools. Generated SQL is parsed and constrained to a single SELECT, scoped to one tenant chosen on the command line, capped on rows, run time and turns, and every tool call is logged. When it can't answer safely, it returns a fixed reply, a clarifying question or a validated fallback report instead of guessing.

Equal scores mean the question set was too easy to tell the two prompts apart. I report that as a finding about the eval, not as proof the definitions don't matter. Building the ground-truth SQL for the evals surfaced a mart whose grain missed $347 of lost sales: in-stock items cancelled along with an out-of-stock one. I added a per-order model that measures the full basket loss and the ad cost of cancelled orders.

Trickle-Down Trend Tracker

Personal project, 2026

A theory I expected to confirm, data that contradicted it, and a tool that refuses to guess.

Fashion's old rule says trends start on luxury runways, semi-luxury brands adapt them, and high-street brands mass-produce them last. I tracked weekly news coverage of 14 Fall/Winter 2026 trends across four brand tiers, measuring each trend as a share of its tier's own coverage, because luxury gets far more press no matter what. It measures press momentum, not sales.

Before trusting the method, I tested it on a simulated store with planted delays, noisy data and a null test; the null test caught a flaw, which I fixed. On top sits a planning tool: an early warning from post-show press, a capped buy-plan adjustment and launch timing. When GDELT turned out to be missing whole days, the tool marked those readings "Incomplete data" instead of reporting them. 117 tests.
